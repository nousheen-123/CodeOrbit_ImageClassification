# Image Classification Using a Pretrained Model

## Project Description

This project was developed as part of the CodeOrbit Tech Artificial Intelligence Internship.

The project uses a pretrained ResNet18 image classification model to identify the contents of sample images. The model processes each image and predicts the most likely class label.

## Features

- Uses a pretrained ResNet18 model
- Classifies multiple sample images
- Displays the predicted label for each image
- Uses image preprocessing before prediction
- Does not require training a model from scratch

## Technologies Used

- Python
- PyTorch
- Torchvision
- Pillow
- VS Code
